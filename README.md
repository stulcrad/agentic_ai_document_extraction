# Agentic AI Document Extraction Assignment

This repository contains the code for the Agentic AI Document Extraction assignment. The goal of this assignment is to build a system that can extract structured information from unstructured documents using agentic AI techniques. For this task I chose to extract a defined set of fields from Contract Understanding Atticus Dataset (CUAD).

I chose to extract 7 fields from the CUAD dataset. The fields I selected are:
1. Contract Type
2. Parties Involved
3. Agreement Date
4. Effective Date
5. Expiration Date
6. Renewal Terms
7. Governing Law
